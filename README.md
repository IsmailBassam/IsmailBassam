## Projects

### 🎵 WaveForge — C++ Music Synthesizer
> Generating real audio from pure mathematics. No libraries. No shortcuts.

Built a software synthesizer from scratch in C++ that produces `.wav` files using raw wave mathematics — sine, square, and sawtooth waveforms with full ADSR envelope control. No external audio libraries. Every byte of the WAV header is written by hand. As a demo it renders a 3-track version of Beethoven's Moonlight Sonata.

**What's under the hood:** OOP with abstract base classes, polymorphism, composition, manual binary file I/O, 44.1kHz PCM audio at CD quality.
